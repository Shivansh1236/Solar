# Solar Power Generation Data Dictionary

## Dataset Overview

This project uses operational and weather data collected from two solar power plants in India:
- **Plant 1:** Plant ID `4135001`
- **Plant 2:** Plant ID `4136001`

### Files

#### Raw Files
- `Plant_1_Generation_Data.csv`
- `Plant_1_Weather_Sensor_Data.csv`
- `Plant_2_Generation_Data.csv`
- `Plant_2_Weather_Sensor_Data.csv`

#### Cleaned & Processed Files
- `Plant_1_Generation_Cleaned.csv`
- `Plant_1_Weather_Cleaned.csv`
- `Plant_1_Feature_Engineered.csv`
- `Plant_2_Generation_Cleaned.csv`
- `Plant_2_Weather_Cleaned.csv`
- `Plant_2_Feature_Engineered.csv`

The dataset contains:
- Power generation measurements (DC & AC power)
- Weather sensor readings (ambient & module temperature, solar irradiation)
- Inverter-level production data across 22 unique inverters per plant
- Time-series observations recorded at 15-minute intervals (34 days)

### 5. Feature Engineered Dataset (Plant 1 & Plant 2)

**File Names:** `Plant_1_Feature_Engineered.csv`, `Plant_2_Feature_Engineered.csv`

Created by merging Generation and Weather datasets on `["DATE_TIME", "PLANT_ID"]` and deriving temporal features:

| Column Name | Data Type | Description |
|-------------|-----------|-------------|
| SOURCE_KEY_x | Integer | Label-encoded inverter identifier (0 to 21) |
| AMBIENT_TEMPERATURE | Float | Surrounding air temperature (°C) |
| MODULE_TEMPERATURE | Float | Solar panel surface temperature (°C) |
| IRRADIATION | Float | Incident solar radiation (kW/m²) |
| HOUR | Integer | Hour of the day (0–23) |
| DAY | Integer | Day of the month (1–31) |
| MONTH | Integer | Month of observation (5 or 6) |
| WEEKDAY | Integer | Day of week (0 = Monday, 6 = Sunday) |
| IS_WEEKEND | Integer | Binary indicator (1 = Weekend, 0 = Weekday) |
| AC_POWER | Float | **Target Variable:** Alternating current output (kW) |

## Key Variables for Analysis

The following variables are central for exploratory data analysis and predictive modeling:

- **AC_POWER**: Target variable for regression models.
- **IRRADIATION**: Dominant predictor of solar generation.
- **MODULE_TEMPERATURE**: Reflects solar heating and cell operating conditions.
- **AMBIENT_TEMPERATURE**: Surrounding climatic thermal conditions.
- **SOURCE_KEY_x**: Accounts for inverter-specific performance and conversion efficiency.
- **HOUR, DAY, MONTH, WEEKDAY, IS_WEEKEND**: Captures diurnal generation cycles and calendar patterns.
