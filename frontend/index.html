ABOUT THE PROJECT

From solar conditions to predicted power.

This project uses historical solar plant generation data to train a Random Forest regression model capable of estimating AC power generation.

The live prediction system retrieves current environmental conditions, prepares them in the same feature format used during training, and sends them to the trained model through a Flask backend.

01 Collect

Retrieve current solar conditions.

02 Prepare

Convert live data into model features.

03 Predict

Generate AC power using Random Forest.

04 Display

Present predicted generation.
