How to interpret this outlook

Each location uses one Open-Meteo hourly weather forecast. The same ambient temperature, shortwave radiation, estimated module temperature, time fields, and numeric source key are sent to both plant-specific models: Plant 1 XGBoost and Plant 2 Random Forest. Irradiation is scaled by dividing shortwave radiation by 1,000; module temperature follows the project's approximation of ambient temperature + 0.025 × radiation. Source key 0 is supplied to each plant model, but the two plants' source-key encodings were trained independently, so it may refer to different physical inverters. AC_POWER is an inverter-level prediction, not total plant output. Each 24-hour energy figure is a simple hourly sum of predicted kW values, not a meter reading or measured energy forecast. Open-Meteo shortwave radiation is an hourly average. All outputs are estimates, not actual inverter measurements.
